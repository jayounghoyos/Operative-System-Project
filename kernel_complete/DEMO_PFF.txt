# ============================================================================
# DEMOSTRACIÓN: PFF (Page Fault Frequency) - Gestión Avanzada de Memoria
# ============================================================================
#
# PFF es un algoritmo avanzado que ajusta dinámicamente el número de frames
# asignados a cada proceso basándose en su tasa de fallos de página.
#
# Ventajas de PFF:
# - Previene thrashing (exceso de swapping)
# - Optimiza uso de memoria entre procesos
# - Balance automático entre procesos con diferentes working sets
#
# Configuración por defecto:
#   - Ventana de medición: 10 accesos
#   - Umbral superior: 60% (si supera, aumentar frames)
#   - Umbral inferior: 10% (si baja, reducir frames)
#   - Frames mínimo: 2 por proceso
#   - Frames máximo: 50% del total
# ============================================================================

clear

# ----------------------------------------------------------------------------

# ----------------------------------------------------------------------------
# CONCLUSIONES
# ----------------------------------------------------------------------------
#
# PFF (Page Fault Frequency) es superior a FIFO y LRU porque:
#
# 1. ADAPTACIÓN DINÁMICA:
#    - Ajusta frames según comportamiento real del proceso
#    - No usa política fija de reemplazo
#
# 2. PREVENCIÓN DE THRASHING:
#    - Si tasa de fallos es alta → asigna más frames
#    - Evita que proceso entre en thrashing
#
# 3. EFICIENCIA EN MULTIPROCESAMIENTO:
#    - Procesos con locality bueno liberan frames
#    - Frames van a procesos que los necesitan más
#
# 4. WORKING SET AUTOMÁTICO:
#    - No requiere que programador especifique working set
#    - Se calcula automáticamente por observación
#
# TRADE-OFFS:
# - Mayor complejidad de implementación
# - Overhead de tracking por proceso
# - Requiere configuración de umbrales (pero son robustos)
#
